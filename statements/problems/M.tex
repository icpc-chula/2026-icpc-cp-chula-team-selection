\begin{problem}{M}{Mitsuhiko's Lamp Game}{1 second}

\noindent
Professor Agasa has built yet another invention: the Lamp Board, a long strip of $N$ lamps, each of which is either lit or unlit. To test it, the Detective Boys came up with a game. Before each round, Mitsuhiko picks a segment of consecutive lamps and covers every other lamp with a cloth, so only the lamps inside the segment are in play. Then Ayumi and Mitsuhiko take turns switching lamps off, and whoever cannot make a move loses.

\noindent
After an entire afternoon, Mitsuhiko has lost round after round, no matter how hard he concentrates. Genta blames it on his empty stomach, but Conan notices something else: once the segment is chosen, the winner is already decided, because both players always play perfectly. Haibara bets that Conan cannot work out how many of the possible segments are already lost for Mitsuhiko before the round even starts.

\noindent
Write the lamps in play as a bitstring $T$, where $1$ is a lit lamp and $0$ is an unlit lamp. Ayumi and Mitsuhiko take turns, and Ayumi moves first. On each turn, the current player performs exactly one of the following operations:

\begin{itemize}
\item Change $3$ consecutive ones into zeros.
\item Change a group of size $1$ or $2$ into zeros.
\end{itemize}

\noindent
A group is a maximal segment of consecutive ones in $T$, i.e., a segment of ones that cannot be extended to the left or to the right.

\noindent
A player who cannot make a move loses.

\noindent
You are given the whole Lamp Board as a bitstring $s = s_1 s_2 \ldots s_N$. Count the number of pairs $(l, r)$ with $1 \le l \le r \le N$ such that Ayumi wins when the game is played on $T = s_l s_{l+1} \ldots s_r$ and both players play optimally.

\noindent
Note that groups are taken with respect to $T$, the string the game is played on, not with respect to $s$: the covered lamps are not part of the game.

\noindent
\textit{There is always only one truth!} Help Conan win the bet.

\InputFile

\noindent
The first line contains a single integer $N$ ($1 \le N \le 1\,000\,000$)~--- the number of lamps.

\noindent
The second line contains a bitstring $s$ ($|s| = N$ and $s_i \in \{1, 0\}$)~--- the state of each lamp.

\OutputFile

\noindent
Print a single integer~--- the number of pairs $(l, r)$ such that Ayumi wins.

\Examples

\begin{example}
\exmp{1}{4
1111
}{9
}
\exmp{2}{7
0110111
}{17
}
\end{example}

\end{problem}
