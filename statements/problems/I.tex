\begin{problem}{I}{Inhabited Islands}{1 second}

\noindent
During a summer vacation, Conan and the Detective Boys visited the Jabberwock Archipelago. This archipelago consists of $N$ islands connected by exactly $N-1$ bridges, forming a network that allows travel between any two islands. However, the bridges are not entirely secure. Each bridge is assigned a specific danger level, which can be a positive, negative, or even zero value.

\noindent
To ensure their adventure remains relatively risk-free, the Detective Boys defined an unordered pair of distinct islands $(u, v)$ as ``safe'' if the simple path between them strictly meets two conditions.

\begin{itemize}
\item the \textbf{sum} of the danger levels of all bridges on the path must be \textbf{negative}.
\item the \textbf{product} of the danger levels of all bridges on the path must also be \textbf{negative}.
\end{itemize}

\noindent
Your task is to help Conan analyze the archipelago. You must count the total number of ``safe'' unordered pairs of islands. Additionally, for each island, you need to find the smallest island index that forms a ``safe'' pair with it.

\InputFile

\noindent
The first line of the input contains a single integer $T$ ($1 \le T \le 10,000$), representing the number of test cases.

\noindent
The first line of each test case contains a single integer $N$ ($1 \le N \le 10^5$), denoting the number of islands.

\noindent
Each of the next $N-1$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le N$, $-10^9 \le w \le 10^9$), representing a bridge connecting island $u$ and island $v$ with a danger level of $w$. It is guaranteed that the given edges form a valid tree.

\noindent
The sum of $N$ over all test cases does not exceed $10^5$.

\OutputFile

\noindent
For each test case, output two lines. On the first line, output a single integer representing the total number of ``safe'' unordered pairs.

\noindent
On the second line, output $N$ space-separated integers, where the $i$-th integer is the smallest island index that forms a ``safe'' pair with island $i$, or $-1$ if no such island exists.
