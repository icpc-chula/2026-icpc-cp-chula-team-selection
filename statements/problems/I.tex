\begin{problem}{I}{Inhabited Islands}{2 seconds}

\noindent
During a summer vacation, Conan, Ran and Sonoko visited the Jabberwock Archipelago. The archipelago consists of $N$ islands connected by exactly $N-1$ bridges, so that it was possible to travel between any two islands. 

\noindent
Centuries earlier, a massive ghost outbreak had occurred in the archipelago. The priests worked tirelessly to seal the spirits into the piers of the bridges, and ever since then, the bridges had been regarded as sacred places. Each bridge carried a \textbf{spiritual level}, which could be positive, negative, or even zero.

\noindent
That summer, the villagers wanted to host a festival and needed a simple path to serve as the street for the carnival. The village elder told the group that a path between two distinct islands $u$ and $v$ was considered ``safe'' if both the \textbf{sum} and the \textbf{product} of the spiritual levels of all bridges on the path were \textbf{negative}.

\noindent
Help the village elder count the total number of safe simple paths, where the paths from $u$ to $v$ and from $v$ to $u$ count as the same path. Additionally, for each island, find the \textbf{smallest} index of an island that forms a safe path with it (or report $-1$ if there is none).

\InputFile

\noindent
The first line of the input contains a single integer $T$ ($1 \le T \le 10,000$), representing the number of test cases.

\noindent
The first line of each test case contains a single integer $N$ ($2 \le N \le 2 \cdot 10^5$), denoting the number of islands in the Archipelago. 

\noindent
Each of the next $N-1$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le N$, $ |w| \le 10^9$), representing a bridge connecting island $u$ and island $v$ with a spiritual level of $w$. It is guaranteed that the given edges form a valid tree.

\noindent
The sum of $N$ over all test cases does not exceed $2 \cdot 10^5$.

\OutputFile

\noindent
For each test case, output two lines. On the first line, output a single integer representing the total number of ``safe'' unordered pairs.

\noindent
On the second line, output $N$ space-separated integers, where the $i$-th integer is the smallest island index that forms a ``safe'' pair with island $i$, or $-1$ if no such island exists.
