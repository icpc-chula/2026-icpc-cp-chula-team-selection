\begin{problem}{D}{death\_of\_the\_camel}{1 second}

\noindent
Prof. Agasa has recently started organizing his book collection on his computer. For each book, he has stored the author's name in \textbf{camelCase}.

\noindent
A \textbf{camelCase tokenization} of a string is a partition into contiguous, non-empty tokens such that:

\begin{itemize}
    \item the first token consists only of lowercase English letters;
    \item every other token consists of either one uppercase English letter followed by zero or more lowercase English letters, or one or more uppercase English letters.
\end{itemize}

\noindent
For example, \texttt{georgeRRMartin} can be tokenized as $[\texttt{george}, \texttt{RR}, \texttt{Martin}]$ or $[\texttt{george}, \texttt{R}, \texttt{R}, \texttt{Martin}]$. However, $[\texttt{george}, \texttt{RRM}, \texttt{artin}]$ is invalid because \texttt{artin} starts with a lowercase letter.

\noindent
The \textbf{snake\_case conversion} of a tokenization is obtained by converting every token to lowercase and joining adjacent tokens with \texttt{\_}. For example, $[\texttt{george}, \texttt{RR}, \texttt{Martin}]$ becomes \texttt{george\_rr\_martin}.

\noindent
Given a string $S$ that admits at least one valid camelCase tokenization, find the \textbf{lexicographically largest} possible snake\_case conversion.

\noindent
For lexicographical comparison, characters are ordered as
$\texttt{\_} < \texttt{a} < \texttt{b} < \cdots < \texttt{z}$.
A string $A$ is lexicographically smaller than a different string $B$ if $A$ is a prefix of $B$, or at the first position where they differ, the character in $A$ is smaller than the character in $B$.

\InputFile

\noindent
The input consists of a single string $S$ ($1 \le |S| \le 50$).

\noindent
$S$ consists only of uppercase or lowercase letters and admits at least one valid camelCase tokenization.

\OutputFile

\noindent
Output the \textbf{lexicographically largest} snake\_case conversion of $S$.

\Examples

\begin{example}
\exmp{1}{georgeRRMartin
}{george_rr_martin
}
\exmp{2}{monkeyDLuffy
}{monkey_d_luffy
}
\exmp{3}{xDD
}{x_dd
}
\exmp{4}{goshaooyama
}{goshaooyama
}
\end{example}

\end{problem}
